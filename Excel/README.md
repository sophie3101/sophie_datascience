# Shortcut

: to the end of the sheet
| ShortCut | Purpose |
:------------------------------- | :-------------------- |
|Ctrl + End | To the end of page |
|Ctrl + Home | Move to the top |
|Ctrl + -> | Move across columns |
| Ctrl + Spacebar | select entire column |
| shift + Spacebar | Select entire row

Using keychron keyboard, the 'Alt' button is the 'Command button'
